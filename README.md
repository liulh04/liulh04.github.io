# LiuLanker Personal Site

Source for [liulh04.github.io](https://liulh04.github.io/), a personal portfolio focused on efficient large language models, AI systems, and IoT.

## Local preview

Open `index.html` in a browser. The site uses plain HTML and CSS and requires no build step.

## Structure

- `index.html` contains the profile, selected projects, and public links.
- `styles.css` contains responsive layout, typography, and color tokens.
- `img/` contains the existing profile illustration and legacy assets.

## Deployment

GitHub Pages serves the site from the repository's configured branch. Keep public profile copy and contact links accurate before publishing changes.
